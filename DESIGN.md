# Working State design

These rules apply to the Working State workspace. The approved screens, responsive behavior, and prototype are documented in the [workspace design](docs/workspace-design.md).

## Color

- **Use charcoal surfaces, off-white text, and neutral gray selection. Reserve muted amber for the In progress indicator.** The neutral palette was approved after the earlier tinted palettes were rejected.
  <!-- 2026-11-25 user feedback: "I want a dark theme." "These colors look like ai slop." "This is much much better." -->

## Surfaces

- **Use dark translucent glass for workspace chrome, including navigation and search. Keep the surfaces behind task content visually quiet.** This gives the workspace the approved finish while keeping the work area uncluttered.
  <!-- 2026-11-25 user feedback: "I'd like more of like a dark transparent glass look." "This is much closer." -->
- **Dock desktop task details flush with the main workspace on one continuous glass surface. Use a single 1 px vertical divider and a shared outer frame.** The task pane should feel like part of the same workspace.
  <!-- 2026-11-25 user feedback: "it shouldn’t look separate but just a small line that shows the division" -->

## Layout

- **Give the task list the most space in effort views. Keep updates compact and collapsible, and put recent tasks behind a disclosure.** The task list is the main working area. Updates and recent tasks should be easy to reach without crowding it.
  <!-- 2026-11-25 user feedback: "the task list probably, as far as that pane, I would say needs to be the largest, because that's more of your working area" and "I just don't want cluttered" -->

## Interaction

- **Open tasks from lists, search, and updates in a right-hand pane on desktop. Keep the originating view visible where space allows.** This lets people inspect a task while keeping their place in the effort or search results.
  <!-- 2026-11-25 user feedback: "being able to click them and go to the task to see more easily would be good" and "I imagine task details kind of slide in from the side into, like, a little right pane." -->
